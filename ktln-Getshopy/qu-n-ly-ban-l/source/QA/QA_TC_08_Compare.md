# Kịch Bản Kiểm Thử Chuyên Sâu - Màn Hình So Sánh Thiết Bị (Compare)

Tài liệu này chứa ma trận **200 Test Cases** chuyên biệt cho tính năng So sánh song song (Side-by-side Comparison). Tập trung test thuật toán tự động gióng hàng cấu hình (Specs Alignment) và thuật toán Highlight điểm khác biệt.
